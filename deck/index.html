How version N+1 is made

Every change has to prove itself before it ships

01 · READ

Shared Brain

Every role reads its slice of memory before it works. Entries are 280 characters and need a cited measurement to get in.

02 · WORK

Nemotron team

Planner, Layout and Checker roles solve the task on Crusoe Managed Inference.

03 · SCORE

Verifier

The verifier recomputes the answer and returns a number. It doesn't use an LLM judge, so no agent can argue with the score.

04 · PROPOSE

Research paper

A research agent proposes one typed change (a prompt, tool, playbook step or config) and predicts how much it will help.

05 · GATE

Keep or reject

The team reruns the dev set with and without the change. It is kept only for a measured gain or a 15% cost cut. Held-out tasks score the final version.
