How version N+1 is made

Every change has to prove itself before it ships

01 · READ

Shared Brain

Every role reads its slice of memory before it works. Entries are 280 characters and need a cited measurement to get in.

02 · WORK

Nemotron team

Nemotron solver and reviewer roles solve the task on Crusoe Managed Inference.

03 · SCORE

Verifier

The verifier recomputes the answer and returns a number. No LLM judge, so no agent can argue with the score.

04 · PROPOSE

Research paper

The Reviewer reads You.com search results, then proposes one typed change (prompt, tool, playbook step or config) and predicts the gain.

05 · GATE

Keep or reject

The team reruns the dev set with and without the change. It is kept only for a measured gain or a measured cost cut.

Kept changes publish as papers to SA's Library.
The final version is scored on held-out tasks it never saw.
